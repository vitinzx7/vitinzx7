## 🚀 Projetos em destaque

### 🔎 JobSonar

Aplicação para centralizar e organizar oportunidades de emprego, facilitando o acompanhamento de vagas durante a busca profissional.

**Tecnologias:**

* Java
* Spring Boot
* APIs REST
* MySQL
* React
* TypeScript

**Principais objetivos:**

* Cadastro e organização de vagas
* Filtros por tecnologia, empresa e modalidade
* Acompanhamento do status das candidaturas
* Autenticação e controle de usuários

> Projeto em desenvolvimento e principal projeto do meu portfólio.

---

### ⏱️ CronoLog

Aplicação para registrar e analisar como o tempo é utilizado durante o dia.

O sistema permite cronometrar atividades como estudo, descanso, sono e entretenimento, adicionando observações e exibindo os registros em um calendário.

**Principais funcionalidades planejadas:**

* Cronômetro de atividades
* Registro de anotações
* Histórico diário
* Visualização em calendário
* Relatórios de produtividade
* Organização por categorias

> Projeto criado para praticar desenvolvimento full stack, lógica de programação e organização de dados.

# Hi, I'm Victor 👋

I'm a technology student focused on **Backend Development with Java and Spring Boot**.

I build projects to strengthen my skills in **REST APIs**, databases, web development, cloud deployment, and application security.

I also study the fundamentals of **Information Security**, **Computer Networks**, **Linux**, and how systems work.

### Tech Stack

- **Backend & APIs:** Java, Spring Boot, Spring MVC, Spring Data JPA, Hibernate, Maven, REST APIs, and external API integrations
- **Databases & Migrations:** PostgreSQL, MySQL, H2, and Flyway
- **Frontend:** React, TypeScript, JavaScript, Vite, React Router, HTML, and CSS
- **Cloud & DevOps:** Docker, Docker Compose, Azure Container Apps, Azure Container Registry, Azure Database for PostgreSQL, Azure Log Analytics, Git, and Linux
- **Testing & Quality:** JUnit, Mockito, MockMvc, AssertJ, ESLint, and Oxlint
- **Additional Learning:** Python, Chrome Extensions with Manifest V3, and Google Analytics 4

### Security Focus

I study and apply secure development practices, including **authentication and authorization**, **Spring Security**, **BCrypt password hashing**, **DTOs**, **input validation**, **CORS**, **CSRF**, **XSS**, **IDOR/BOLA**, **environment-based secrets**, and the **principle of least privilege**.
